# Hospital SQL Report Generator (Python Automation Project)

## Project Overview
This project is a Python-based data automation system that connects to a SQL Server database to generate automated hospital reports.

It extracts patient and treatment data, performs analysis and produces:
- Excel reports
- Data summaries
- Visual charts

The system simulates a real-world hospital reporting tool used for decision-making and data analysis.

---

## Features
- Connects to SQL Server database
- Retrieves patient and treatment data
- Generates automated reports
- Exports data to Excel files
- Creates data visualizations (charts)
- Search functionality for patients
- Date filtering for treatment records
- Menu-driven user interface

---

## Technologies Used
- Python
- SQL Server
- pandas
- pyodbc
- matplotlib
- openpyxl

## How to Run the Project
### 1. Clone the repository
```bash
git clone https://github.com/NeoTech-Labs/python-hospital-report-system.git
```
### 2.Navigate to the Project Folder
```bash
cd python-hospital-report-system
```
### 3.Install required libraries
```bash
pip install pandas pyodbc matplotlib openpyxl
```
### 4.Set up SQL Server
- Ensure SQL Server is running
- Download the provided HospitalDatabase
- Run the queries on SQL Server

### 5.Run Application
```bash
python main.py
```
